# 3. 実装前に追加したい共通基盤

## 3.1 WorldState / StoryState

NPC・MAP・日記・会話・復興状態を大量に変えるため、booleanの乱造だけでなく意味付き状態を持てる仕組みを推奨。

例：

```js
worldState = {
  fireVillageRecovery: 0,       // 0災害中 1解決直後 2復興中 3終盤
  lunaPublicIdentityKnown: false,
  lunaMemoryStage: 0,
  leonJosephRelationStage: 0,
  hayateZeliedTruthStage: 0,
  churchPoliticalState: 0,
  alanOutcome: 'active' // active / betrayed / dead / saved / rejoined
}
```

既存saveとの互換性を保つため、ロード時のdefault補完／save version migrationを必ず用意する。

## 3.2 NPC条件

最低限区別する：

- キャラを**加入済み**か。
- 現在**同行可能状態**か。
- 現在の**戦闘編成**にいるか。
- 特定真実を**プレイヤーが知った後**か。
- 地域の復興state。

用途：レオン加入後の王国NPC、シャニー同行時の炎の里、ハヤテ＋ゼリード、ルーナ正体判明後の街等。

## 3.3 Cutaway Scene

大灯台／海底火山攻略中に光の宮殿内部事件を見せるため、プレイヤー位置を壊さず別MAP／別キャストの場面を再生できる共通処理を追加したい。

必要機能：

1. 現在MAP／座標／向き／BGM等を退避。
2. 指定MAPへ演出用遷移。
3. 一時キャラクターでイベント実行。
4. 元の状態へ完全復帰。
5. セーブ禁止区間または安全な中断復帰を考慮。

## 3.4 イベント専用ボス

負けイベント・弱体版・プロローグ版が図鑑コンプリートの取り返しのつかない要素にならないよう一般化。

候補フィールド：

```js
{
  bestiaryExcluded: true,
  noDrops: true,
  noExp: true,
  forcedLoss: false,
  hpFloor: null,
  endAfterTurns: null,
  endAtHpPercent: null,
  storyVariantOf: null
}
```

`bestiaryExcluded` は図鑑登録だけでなく**図鑑分母からも除外**する。

## 3.5 種族／勢力／属性の分離

新版では「魔族種族」「ゼノン軍」「闇属性」「混沌汚染」は同義ではない。

推奨データ：

```js
{
  race: '魔族',
  faction: 'DEMON_KING_ARMY',
  element: 'dark',
  chaosCorrupted: false
}
```

暗黒騎士は人間race＋教団faction＋chaosCorrupted等にできる。

## 3.6 図鑑文章の知識段階更新

可能なら図鑑説明をプレイヤー知識stateで更新する。

序盤：「魔族との関連が疑われる黒き騎士」
真相後：「王国人間を混沌属性で改造した暗黒騎士」

ミスリードとゲームUIを一致させる。

# 4. ルーナ（ID401）専用成長仕様【確定】

## 4.1 基本

- レアリティ：UR。
- 正式加入：**Lv1**。
- UR通常時の基礎経験値要求は元々やや重い。
- さらに加入直後は**必要経験値倍率2000%**。
- 神性が消えたのではなく、ジャスパーの呪縛で成長・出力経路を封じられている。

### 実装注意

「200%ダウン」は数学的な20割減ではない。

**2000% → 1800%** のように「percentage points」を引く。

内部表現例：

```js
luna.expMultiplier = 20.0; // 2000%
```

または整数：

```js
luna.expMultiplierPct = 2000;
```

整数管理の方が安全。

## 4.2 固定イベント

|イベント|EXP|倍率変更|
|---|---:|---:|
|正式加入|—|2000%開始|
|結晶樹クリア|+300,000|2000→1800%|
|魔王城クリア|+300,000|1800→1600%|
|火精霊|+300,000|-100pt|
|水精霊|+300,000|-100pt|
|風精霊|+300,000|-100pt|
|雷精霊|+300,000|-100pt|
|光精霊|+300,000|-100pt|
|闇精霊|+300,000|-100pt|
|六精霊完了時|累計+1,800,000|1000%到達|
|アルス×ルーナ連続SQ×5|要調整|最終100%|

六精霊終了時までの固定ストーリーEXP合計：**2,400,000**。

アルス×ルーナ5連続クエストで1000%→100%へ戻す。5段階の個別配分はシナリオ確定時に設定する。

## 4.3 二重取得防止

各イベント報酬は一度だけ。

推奨：

```js
storyRewards.lunaCrystalTree = true;
storyRewards.lunaDemonCastle = true;
storyRewards.lunaSpiritFire = true;
// ...
```

倍率を「現在値から引く」だけにするとイベント二重発火で壊れるため、**イベント完了後の倍率を絶対値でsetする方式も検討**。

例：結晶樹完了後は必ず1800へset。

## 4.4 大量EXP処理

+300,000で複数Lv飛ぶことを前提にする。

- `while (exp >= nextExp)` 相当の反復レベルアップ。
- 飛ばした各Lvの技能習得を漏らさない。
- LvUPポップアップを大量連打しない。
- 上限Lvでoverflowしない。

## 4.5 Lv1スキル

聖女Lv1の治療／浄化／バフを大幅強化する。

意図：

**低Lv＝弱い聖女ではなく、出力を奪われた最上位ヒーラー。**

攻撃・HP・MPは低くてもよいが、治療効率・浄化・耐性バフには明確な価値を持たせる。

# 5. アラン（ID201）状態機械【確定】

## 5.1 推奨状態

```js
alanState = {
  phase: 'joined', // joined / betrayed / boss / dead / saved / rejoined
  equipmentReturned: false,
  appealDocumentObtained: false,
  rejoinExpGranted: false
}
```

## 5.2 海底神殿後

- アラン家旧屋敷で加入。
- 船入手。
- 職：魔法戦士。

## 5.3 光の宮殿裏切り

離脱直前に**全装備を自動返却**。

処理順が重要：

1. 装備をinventoryへ戻す。
2. `equipmentReturned=true`。
3. パーティ／加入可能リストから離脱。
4. `phase='betrayed'`。

再ロード・イベント再入場で二重返却しない。

## 5.4 ハヤテ連続クエスト

- ゼリード起点。
- アラン父の汚名を雪ぐ。
- ハヤテ父・ゼリードの過去へ繋がる。
- 終盤にハヤテ加入。
- 完遂報酬キーアイテム：**王への上申書**。

`王への上申書` はアラン救済ルート必須。

## 5.5 統合の祭壇・戦闘前

### 上申書あり

通常通り戦闘へ。
戦闘後に生存／救済ルートを使用可能。

### 上申書なし

専用会話を必ず実行：

- ジョセフ
- レオン
- クロード
- レイラ
- ゼリード

の苦悩を強める。

ガイル／サラにも「本当にこのまま倒していいのか」「仲間だった」という趣旨を言わせる。

その後：

```text
進む
引き返す
```

を提示。

**引き返す：** MAPを戻り、救済条件を探せる。  
**進む：** アラン戦。撃破後死亡確定。

これは意図的な不可逆要素。勝利後に「やっぱり助ける」は不可。

## 5.6 アラン死亡

```js
alanState.phase = 'dead'
```

以後：

- 再加入不可。
- 蘇生不可。
- 上申書新規取得不可。
- 未発生／未完了のハヤテ加入関連クエストは発生不可または失敗状態へ。
- NPC／エンディング／アーカイブ差分。

セーブデータ上で永久保持する。

## 5.7 アラン救済／再加入

上申書所持＋救済ルート選択後：

- `phase='saved'`。
- 後の再加入イベントで職業変更：**魔法戦士 → 光魔剣士**。
- 内部経験値：**+500,000**を一度だけ付与。
- `rejoinExpGranted=true` で二重取得防止。
- `phase='rejoined'`。

光魔剣士用に最低限必要：

- 新職ID／職定義。
- 新成長補正。
- 習得技表。
- 職表示名。
- 必要なら専用アイコン／色／アーカイブ。

既存「魔法戦士」の技を一部引き継ぎ、新たに光属性技能を追加する方向が自然。

7. 水→風→光→火→雷→闇→水…と循環。
8. 焼け焦げたネックレス＋ルーナ共鳴。
9. ルシオン一時顕現。
10. 輪廻の結晶生成。

最終戦：六芒星の同時固定と輪廻の循環が拮抗。

# 12. 取り返しのつかない要素の扱い

基本的には取り返しのつかない図鑑要素等を避ける。

**例外：アランの生死。**

これは作者の明示意図により不可逆。

ただしプレイヤーへは、

- 仲間たちの強い苦悩会話。
- 若者組の制止。
- 「引き返す」明示選択。

を必ず与える。
