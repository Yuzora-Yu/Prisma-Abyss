### 3階・ルーナ封印後の進行保証

- 六芒星イベントの発火範囲は X16〜18 / Y20 のまま維持する。
- 封印成立後のルーナ離脱は、通常時間側の仲間離脱処理を流用しない。回想Scene Context内で、ルーナのUIDを確保したうえで「編成枠から除去 → 回想中charactersから除去 → 回想用story stateを初期化」の順に一体処理する。

- ヴェルドも同様に、画面明滅 → `fx-abyss-vortex-ai.png` を2倍サイズで表示 → ヴェルド画像出現、の順にする。

### ヴェルド回想戦

  - 5ターン終了時。
  - 5ターン未満でもヴェルドがHP1まで削られた時。
- 条件成立後は専用会話を表示し、その後ヴェルドがイベント専用技 **「黒白の葬閃」** を使用する。
- 「黒白の葬閃」は味方全体へ必中・固定9999ダメージを与え、全滅させる。通常戦闘の命中・防御・耐性計算や通常版スキル名は変更しない。

### 1階・結界崩壊後のクロード退場

- 最終回想ヴェルド戦後も、ヴェルドのマップ表示は維持する。
- 結界が消えるタイミングの大きな上下画面揺れは維持する。

- レオンはクロードの北側へ素早く回り込み、北から押す姿勢を取る。
- 押し込む瞬間は、レオンの歩行グラフィックを短時間だけ小さく上下振動させて力を加えているように見せる。
- クロードはヴェルドの接近演出と同程度の速度感で南へ連続移動し、既存台詞「レオン――！」の表示中に画面外へ消える。
- 緊迫した退避場面であるため、ゆっくり交互に押すコミカルな見え方にはしない。

  - ジャスパー: 発火座標から東3・北4。

  5. ジャスパー出現。
  6. ジャスパー台詞。

### イベント描画の安定化

- 永続するイベント演出はDOMの画面座標を正本にしない。PhaserのMAPワールド座標へ配置する。
- 再読込・画面サイズ変更・カメラ移動後も、保存済みMAP座標から同じ位置へ再描画する。
- 描画同期処理はストーリーフラグを変更しない。描画更新だけで六芒星イベントを再着火させない。
- 固定床の一度きりstoryEventは、イベント本文開始前にeventFlagをセーブし、会話開始直後の再読込でも二重発火しないようにする。
- Phaserが利用できない旧Canvasフォールバックでも、DOM演出は各要素のMAPタイル座標から再配置する。

### 退却後の階段

- ヴェルド初戦後は、**一度下りた階へ上り直せない**。退却方向は常に下階・入口側へ固定する。
- 3階から2階へ下りた後、2階の3階行き階段を調べてもクロードの既存制止台詞を表示し、3階へ戻さない。
- さらに2階から1階へ下りた後も、1階の2階行き階段で同じ制止台詞を表示し、2階へ戻さない。
- この制限は `lightPalaceFlashbackActive` かつ `lightPalaceFlashbackRetreatOrdered` の回想退却中だけに適用し、通常時間の宮殿探索には影響させない。


## Phase 15 追補 — 回想レベル・宮殿周辺遭遇・現在時間の地下牢優先導線

承認根拠: 2026-08-19 ユーザー直接指示

### 回想専用キャラクターLv

- レイラ `204`: Lv.49。
- レオン `305`: Lv.62。
- クロード `304`: Lv.58。
- ルーナ `401` は今回の変更対象外とし、既存の回想設定を維持する。

### 光の宮殿グランプリズマ周辺の通常遭遇

- ワールド側 `LIGHT_PALACE_GROVE` の基準Rankは `61` を正本とする。
- 生息地は `MAP000022`（光の宮殿グランプリズマ周辺）の `floor 0` を正本とする。
- `rankMin` / `rankMax` 未指定を `null -> 0 -> Rank1範囲` と誤解釈して、生息地指定よりRank1抽選を優先してはならない。
- 点検の結果、`main.js` のワールド遭遇プロファイル生成と戦闘データ格納で `Number(null) === 0` を有限値として扱っていたことが直接原因だった。未指定境界は戦闘開始後まで `null` のまま保持する。

## Phase 20 追補 — 六芒星9分割描画修正・大型ワールドFX深度・操作ログ整理

承認根拠: 2026-08-20 ユーザー直接指示

### 六芒星が9タイル化後に見えなくなった原因

- 画像の有無ではなく、Phaser側の **crop後scale計算** が原因。
- 六芒星は床と壁の間へ入れるため、元画像をY方向に9分割し、それぞれを対応するMAP行の深度へ置いている。
- 旧処理は `setCrop()` 後に `setDisplaySize()` を呼んでいたが、Phaserの `setDisplaySize()` はcrop矩形ではなく元テクスチャ全体の寸法を基準にscaleを決める。384px画像を9分割した約42〜43px高のsliceに対して32px表示を指定しても、実表示高は約3.5pxになり、各32px行の大半が空白になっていた。
- 4分割時は各sliceが約8px残るため視認できたが、9分割で症状が顕在化した。
- Phase 20ではcrop後の各sliceについて、`targetWidth / sourceWidth` と `targetSliceHeight / cropHeight` を直接scaleへ設定し、9枚を隙間なく元の9タイル画像へ復元する。
- 深度は従来どおり各MAP行の `floor + 46` とし、床本体・床装飾より前、壁 `+48/+49` と人物 `+88` より後ろを維持する。エラーを握り潰して進める対応にはしない。

### ジャスパー／ヴェルド出現時の深淵渦

- `fx-abyss-vortex-ai.png` は4.2タイル高の一枚絵だが、旧実装では中心Y行だけの深度を持っていた。
- 画像下半分が次のY行へはみ出す一方、次行の床はより大きいY深度を持つため、渦の下側が床タイルへ潜って欠けることがあった。
- 出現時の大型一過性FXは専用 `cutscene-front` 深度へ置き、通常MAPの床・壁・人物より前、ミニマップ／画面演出より後ろに表示する。
- ジャスパー／ヴェルド本人の永続MAP座標・通常人物深度は変更しない。

### 救援時のクロード移動

- レイラVSヴェルド後、クロードは南側を **X18/Y24まで右へ走ってから** X18/Y18へ北上する。
- 北上後に右へ1マスずれる旧経路を廃止し、曲がり角を先に通過してから駆け上がる見た目にする。

### 汎用ログと階段ロック表示

- ストーリー `HEAL` は回復処理とSEを維持するが、汎用「不思議な力で体力が回復した！」ログを既定では表示しない。必要なイベントだけ `message` または `log:true` で明示する。
- 固定マップの封印・逆走禁止階段は、踏んだだけでロック理由や会話を自動表示しない。アクションボタンを残し、押した時に `lockedEventId / blockedEventId` があれば会話、なければロック理由を表示する。
- ランダムダンジョンの通常階段も「階段がある。」という自動ログを省き、「次の階へ」アクションだけを提示する。
