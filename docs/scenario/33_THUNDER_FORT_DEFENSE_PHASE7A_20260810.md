# 雷の要塞防衛・ルーナ覚醒 Phase 7A 実装骨格

作成日: 2026-08-10  
基準: PRISMA_SCENARIO_CANON_MASTER_v8 32.15〜32.17 / Phase 6E 宮殿解放後

## この工程の範囲

長台詞の最終稿は確定しない。光の宮殿からの急報を受けて雷の要塞へ戻り、魔王軍直接戦闘①、ルーナ覚醒、記憶喪失の確定提示、結晶樹ルート発生までをプレイ可能な骨格として接続する。

## 正式進行

1. 光の宮殿解放直後は `storyStep 7 / subStep 3`。旧Step8へはまだ進まない。
2. 雷の要塞へ戻ると、バロンたち冒険者ギルドが救護区画を守って籠城している。
3. 魔王軍は要塞全域を破壊せず、一般市民を積極的に狙わない。
4. 魔王軍は補給庫・領土確保を無視して、ルーナのいる救護区画へ一直線に進む。
5. 「聖女を渡せ」「その娘を人間どもに預けておくわけにはいかない」等、現時点では誘拐目的に聞こえる短い発言を置く。
6. アルス一行は二段階の防衛戦で魔王軍を退ける。
7. 戦闘後、ルーナが目を覚ます。
8. レイラは救護班に支えられながらルーナへ謝罪し、抱きつく。
9. アルスは五年間探していた幼馴染へ話しかける。
10. ルーナはアルスを知らず、聖女として丁寧に以下を述べる。

> 「冒険者様、助けてくださってありがとうございます。」

11. この時点で「教団に保護される以前の記憶を失っている」ことをアルスとプレイヤーへ確定提示する。
12. ケイトは、ルーナの力の安定とレオンの深い光の呪いの双方を理由に、結晶樹のより根源的な力を探す必要があると判断する。
13. 次の本編導線は水上都市のソフィア再訪。ミネルバ／結晶樹への接続は次工程で詳細化する。

今回JSへ入れるのは、以下だけ。

- 魔王軍が市民ではなく救護区画へ進んでいること。
- 現時点では誘拐目的に聞こえる魔王軍側の短文。
- ルーナ覚醒の正本確定台詞。
- 結晶樹を必要とする理由の最短説明。

ゼノンの真意、エクリプス側の保護理由、レイラ／アルス／ルーナの長い感情会話は後のDialogue Polishで確定する。
