# 転生職歴復帰・海底火山ワールド導線 追加仕様（2026-08-16）

## 1. 今回の確定事項

- 転生の実を表示Lv100で使う場合、現在職のまま転生するほか、過去に経験した職業へは転職の書なしで戻れる。
- 過去職で習得済みのスキルは従来どおり失わない。
- 職業特性は転生後の現在職だけが有効。
- ワールドマップ右端へ海タイル20列を追加する。
- 海底火山はワールド座標 `(113,17)` に置く。入口1マスは草原タイル（陸地）とし、その上へ洞窟アイコンを表示する。位置関係としてはカザリアよりさらに北東の海上にある。
- 海底火山は大灯台内部からの直通ではなく、船でワールドマップ上の入口へ到達して進入する。
- 雷の要塞と水上都市に「カザリアよりさらに北東、海の中」という位置ヒントを置く。
- スカイプリズムの移動先一覧では、海底火山を大灯台の直下に並べる。
- 海底火山地下1～3階は可変構造を維持するが、迷路生成は使用しない。部屋・洞窟・遺跡系の可変構造だけを使用する。
- 海底火山は地下へ潜るダンジョンとして扱い、深部へ進む階段は下り、浅い階へ戻る階段は上りで統一する。
- 海底火山入口自体は常時進入可能。地下3階「火脈封鎖層」の深部隔壁は `underseaVolcanoRouteOpened` まで施錠され、大灯台クリア後に雷の要塞でバロンたちと話した後は、先行組に破壊された隔壁として地下4階「沈圧研究棟」へ進める。

## 2. 新規会話

### 雷の要塞 / 冒険者

**条件:** `underseaVolcanoRouteOpened=true` かつ `underseaVolcanoCleared=false`

冒険者「海底火山なら、カザリアよりさらに北東だ。陸じゃない。船で外海を探せ。」

冒険者「海面は普通に見えるが、船縁から手を出すと潮だけ妙にぬるい。そこまで行けば入口は分かる。」

### 水上都市 / 船大工

**条件:** `underseaVolcanoRouteOpened=true` かつ `underseaVolcanoCleared=false`

船大工「海底火山？　カザリアよりずっと北東の海だよ。陸影を探しても見つからない。海の中にあるんだからね。」

船大工「あそこだけ船底の松脂が柔らかくなる。湯気なんぞ待つな、潮のぬるさを見ろ。」

### 海底火山 / ワールド入口初回

ゼリード「海面の下から熱が上がってる。ここだ。先に入った連中の痕もある。行くぞ。」

## 3. 本編目的表示

旧:

> バロンたちを追い、海底火山へ向かおう

新:

> バロンたちを追い、カザリアよりさらに北東の海にある海底火山へ向かおう

既存台詞を改稿する目的ではなく、今回ユーザー指定の「海底火山への行き方を明確化する」導線変更に伴う目的文修正として扱う。

## 4. 退出

海底火山地下1階の上り階段から退出した場合は、ワールド座標 `(113,17)` の入口へ戻る。入口の基底タイル自体が陸地なので、エスケープ等の帰還判定でも不安定扱いにならない。
