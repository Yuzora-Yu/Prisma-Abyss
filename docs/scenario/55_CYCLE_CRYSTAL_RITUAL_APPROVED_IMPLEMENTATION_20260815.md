## 1. 確定方針

2026-08-15、旧「オクタプリズマ即時授与」から「結晶樹で輪廻の結晶を生成する」構造への変更について、ユーザー承認を得た。

- 六精霊試練をすべて終えた直後には完成品を付与しない。
- 六つの結晶片が互いに応答し、結晶樹へ戻る必要があることだけを示す。
- 結晶樹の秘跡でミネルバが循環の儀を主導する。
- 循環順は `水 → 風 → 光 → 火 → 雷 → 闇 → 水`。
- 六片は融合して一色にならず、互いへ役割を渡し続ける。
- ルーナと焼け焦げたペンダントが反応し、ペンダントに残ったリュシオンの神性痕跡が儀式を支える。
- リュシオンは完成回答を授ける役ではなく、人間側が到達した理論へ立ち会う。
- Item 701008 は同じIDを維持し、表示名を「輪廻の結晶」へ変更する。
- 旧 `octaprism*` 系の保存キー・戦闘stateはセーブ互換のため当面維持する。
- 終焉の祭壇への正規進入には、イルミナシア撃破・六精霊完了・輪廻の結晶生成の三条件を必要とする。
