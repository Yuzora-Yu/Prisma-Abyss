# 53_ALAN_LIGHT_MAGIC_KNIGHT_AWAKENING_20260815

Date: 2026-08-15  
Status: user-approved / runtime implementation source

## 1. 確定タイミング

対象は、統合の祭壇でアランを生存させた後、災禍の根ジャゴレアでジャスパーを撃破し、プレイヤーがアランの正式再加入を受け入れた瞬間。

その場で加入を保留した場合は、混沌魔城レガシオンで後日正式加入を受け入れた瞬間へ同じ処理を移す。

## 2. 処理順

1. 再加入会話を完了する。
2. アランを利用可能な正式仲間として戻す。
3. 次のシステム会話を表示する。

> システム
> 「光の加護が真にアランの心身と重なり合い、アランは光魔剣士として覚醒した！」

4. 職業を `魔法剣士` から `光魔剣士` へ恒久変更する。
5. 現在レベルまでの光魔剣士習得対象を補完する。
6. その後に Story EXP `+1,000,000` をonce-onlyで付与する。
7. 以後のレベルアップでは光魔剣士の習得表を参照する。

経験値付与を職変更より先に行わない。

## 3. セーブ互換

職業変更はキャラクター保存オブジェクトだけに直書きせず、ストーリー仲間stateへ恒久job overrideを保持する。起動時の旧「master jobへ強制同期」処理はstory job overrideを尊重する。

本仕様実装前のセーブで既に `alanRejoinedAfterJasper` または `alan_jagorea_join_1000k` が成立している場合、覚醒会話を後付け再生せず、光魔剣士への職業状態と現在Lvまでの習得対象だけをmigrationで補正する。

## 4. 再加入後のアラン

再加入は人格の浄化ではない。

- 表面では理知的・礼儀正しく、状況判断も早い。
- アルスを高く評価する一方で、比較されることには強く反応する。
- 承認欲求、敗北への過敏さ、自己正当化、嫉妬は残る。
- 自分の過ちを理解していても、毎回素直に謝罪や感謝を口にする人物にはしない。
- 協力行動と刺のある発言が同居してよい。
- 追い詰められた時の危うさは、父・家名・能力比較・過去の裏切り等の具体的な刺激に結びつける。

外部作品の固有台詞・口調・展開を直接模倣せず、二面性、競争心、危うさだけをアラン固有の履歴へ落とし込む。
