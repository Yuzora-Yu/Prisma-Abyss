# Phase8B — 魔王城三幹部／ガルヴァニア帝国施設再編

**Date:** 2026-08-10  
**Status:** user-directed implementation  
**Scope:** 三幹部会話更改、三幹部の男性設定明文化、魔王城クリア後ショップの帝国移管

## 1. ユーザー確定事項

- 常闇のゼルドラス、風詠のエルメナス、冥騎士ベレトは**三名とも男性**。
- ゼルドラス／エルメナスは、人間側を信用できないためアルスたちを通さない。
  - 「聖女を置いて去れ」
  - 「闇のプリズムだけは人間に利用させない」
  を戦闘理由として使用可能。
- ベレトは思想差に強い関心を持たず、魔王ゼノンへの謁見資格を実力で試す戦闘脳として差別化する。
- ガルヴァニア帝国の武器屋・防具屋など各種商業施設は、魔王城クリアまでは利用不可。
- 旧魔王城1Fに `darkCastleCleared` 後だけ出現していた道具／武器／防具ショップはガルヴァニア帝国へ移管する。

## 3. ガルヴァニア帝国・商業施設

### 配置

- 雑貨店: local x:9, y:11
- 武器店: local x:9, y:21
- 防具店: local x:45, y:21
- すべて既存道路 `T` 上で、ワールド入口→魔王城正門の主経路を塞がない。

### 魔王城クリア前

施設NPC自体は見えるが、取引はできない。

- 雑貨店: 商品箱を閉じ、こちらを警戒している。
- 武器店: 炉を落とし、武器を鎖で固定している。
- 防具店: 城から営業許可が出るまで客扱いしない。

プレイヤー向けに「フラグが足りない」等の内部条件は表示しない。

### 魔王城クリア後

`darkCastleCleared` を条件に同じNPCが通常ショップへ遷移。

- `item` / Rank 65 / 「ガルヴァニア帝国 雑貨店」
- `weapon` / Rank 65 / 「ガルヴァニア帝国 武器店」
- `armor` / Rank 65 / 「ガルヴァニア帝国 防具店」

旧魔王城1Fの3ショップは削除する。魔王城は攻略／謁見／防衛中枢、帝国側を生活・商業圏として分離する。

## 4. 情報境界

- 三幹部はここで「魔王軍は実は正義だった」と説明しない。
- 人間側への不信は、エクリプスから闇プリズムを奪われた経験に根差す。
- ゼルドラスはルーナを単なる鍵・物品として扱う構図にしない。ルーナ本人が「自分で来た」と返す。
- エルメナスはプレイヤーへ正解を教えず、「見たものを自分で考えろ」と促す。
- ベレトは政治説明をせず、実力試験として戦う。
- シャニーと三幹部の「育ての親」関係はこの三戦だけで全説明せず、後続の城内／クリア後会話へ余地を残す。
