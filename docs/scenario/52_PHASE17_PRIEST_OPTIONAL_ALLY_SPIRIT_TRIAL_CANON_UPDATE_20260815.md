## 3. 汎用 story action `IF_ALLY`

任意加入キャラの有無で本筋会話を変えるための共通action。

```js
{
  type: 'IF_ALLY',
  charId: 402,
  mode: 'recruited',
  then: [ ... ],
  else: [ ... ]
}
```

### fields

- `charId` / `charIds`: 対象キャラクターID。複数指定可能。
- `mode`:
  - `recruited`: 一度正式加入している。
  - `available`: 現在、仲間として利用可能。
  - `party`: 現在の実パーティ内にいる。
- `match`:
  - `all`（default）: 全員一致。
  - `any`: 誰か一人でも一致。
- `state`: default `true`。`false` なら条件を反転する。
- `then` / `else`: 通常のstory action配列。

managed event journalでは選択した分岐を保存するため、途中セーブ／再開で加入状態が変わっても同じ会話の途中で分岐が飛ばない。

## 5. ヴェグナシス正本補正

終焉の祭壇のヴェグナシスは五楔。

- 火：グラド
- 水：シーリス
- 風：エリシア
- 雷：レナード
- 闇：ヴェルド

ジャスパーは災禍の根ジャゴレアで撃破された段階で深淵王から見限られ、消滅済み。終焉の祭壇で再利用・再浄化しない。

ルーナは楔ではなく統合核／触媒側。六精霊の「六属性」と、ヴェグナシスの「五楔」は同数である必要がない。
