# 0. この稿のロック事項

本稿は、以下の正本を崩さない。

- アランは「操られているだけ」ではない。深淵は本人に元からある傷・嫉妬・怒りを増幅している。
- 父アレルの真実を知っても、アランは即座に和解しない。
- アラン救済条件は、ゼリード起点の長編クエストを完遂してキーアイテム**「王への上申書」**を所持していること。
- 上申書なしでは、戦闘前に仲間たちの苦悩を描き、必ず**「進む / 引き返す」**を選ばせる。
- 上申書なしで「進む」→撃破した場合、アランは死亡。後から蘇生・救済・再加入はできない。
- 上申書ありでも、父の潔白を見せただけで戦闘そのものが消えることはない。
- 上申書ありなら、戦闘後に「共に生きろ」と手を伸ばす救済選択が開く。
- 救済したアランの**光魔剣士化 / +500,000EXP / 再加入は“後の再加入時”**。祭壇で即加入させない。
- ハヤテはゼリードを即座に許さない。一度完全に関係を壊してよい。
- ガルヴァニア渓谷の門を壊したのはアランだが、Phase8A/8Dでは伏せた。統合の祭壇で初めて回収してよい。
- 統合の祭壇を突破して初めて、旧 `abyss_unsealed` 相当の深淵進行へ入る。

# 1. Phase 8Eの目的

このPhaseの中心は「父は無実だった」という情報そのものではない。

1. ゼリードが、自分の罪をハヤテへ告白する。
2. ハヤテが、父の死を“物語上の材料”ではなく自分自身の傷として受け取る。
3. 王国が、過去の粛清を「ジャスパーだけの悪事」にして逃げず、自国の公的責任として記録へ残す。
4. アランへ真実を届けても、失った十年と本人の劣等感は消えない。
5. プレイヤーが、救済条件を探してきたかどうかによって取り返しのつかない結果を引き受ける。

「正しい情報を持っていれば説得成功」というイベントにしない。

上申書は説得アイテムではない。

**アランへ“戻れ”と言う側が、本当に過去を掘り返し、罪を認め、傷つく当事者と向き合った証拠**として機能させる。

# 8. Stage 5 ― 王への上申書

## 8.1 アイテム名を変えないための意味づけ

キーアイテム名は正本どおり**「王への上申書」**。

これは最初から王が発行する証明書ではない。

アルスたちが、集めた記録と証言をまとめ、

- アレル＝レクスノート侯爵への反逆認定の再審
- カゲトラへの処断命令経路の再調査
- 王国記録への訂正

を求めて**王へ提出する上申書**。

国王はその上申書を受理し、王印と自筆の受理文を加える。

したがって、アイテムとしては最後まで「王への上申書」のまま、
アランへ見せた時には「仲間が勝手に作った紙」ではなく、**王国が公式に過去の誤りを認めて再審へ動いた原本**になる。

- `arelArchiveEvidenceFound`

- `alanAltarBattleCleared`
- `alanAltarResolved`
- `alanDeadAtIntegrationAltar`
- `alanSavedAtIntegrationAltar`

## 19.4 旧save救済

既に旧runtimeでStep10以降へ進んでいるsaveを、統合の祭壇へ巻き戻してアランの生死を強制決定させない。

推奨：

- `storyStep >= 10` かつ `alanAltarResolved` 未設定の旧saveは `alanAltarLegacyBypass=true` を付ける。
- `alanOutcome` を勝手に `dead` / `saved` へ決めない。
- アラン生存／死亡専用の後続イベントは、このlegacy bypassでは発火させない。
- 将来、旧save向けの明示選択救済を作る場合は別Phaseで設計する。

プレイヤーが選んでいない道徳的結果をmigrationで捏造しないことを優先する。
