# 海底火山深部ゲート・固定試練・町導線補正（2026-08-16）

## 海底火山

- ワールド入口は常時進入可能。
- 地下1～3階は可変探索。迷路型は使用しない。
- 地下3階の下り側には深部隔壁がある。`underseaVolcanoRouteOpened` 未成立時は古い錠で閉ざされている。
- 大灯台クリア後、雷の要塞でバロン／フリーダ／マリーのブリーフィングを聞くと `underseaVolcanoRouteOpened` が成立し、隔壁は先行組に破壊された状態として通過可能になる。
- 地下4階は「沈圧研究棟」、地下5階は「深海調律炉」。地下5階中央に炎楔のグラドを配置する。
- 固定ボス階には試練の天使を生成しない。固定ダンジョンで試練の天使が出る場合、左右は現在階の `encounterRank`、中央だけ+5～+9Rankとし、深淵ランダム階用の追加能力倍率は適用しない。

## リースの山小屋

- 外周・小屋内とも本編進行にかかわらず出入り可能。
- 小屋内に寝台を2台配置。
- リースとの会話時は無料休憩としてHP/MPを全回復する。旅立ち後は休息を促す会話を表示する。

## 水上都市リヴァリア

- 依頼仲介人本人が依頼一覧を開く。存在しない掲示板への誘導は行わない。
- 復旧後の噴水を旧位置から左3・上1の `(19,13)` へ移動。
- 噴水は `overlay_shrine_healing_spring` と shimmer 表現を使用する。
- 噴水復旧後に同座標を使っていたソフィアの後半配置は `(18,13)` へ移動する。

## 地名方針

固定ダンジョンの階層名を全体確認し、開発上の機能名だけに見える「戦闘エリア」「研究区画」「制御核区」や、同名の「結界の間」などは地域固有の語彙へ置き換える。既に「旋風の回廊」「逆潮祭壇」のように場所の記憶に結びつく名称は維持する。

深淵世界後半の固定ダンジョンも「1層／2層…」だけだった表示を廃止し、黒縄のピラミッド＝「黒砂玄門／雷鎖回廊…」、魔風の霊廟＝「亡風参道／風葬回廊…」、氷刻の浄罪路＝「白罪門／氷鏡回廊…」、灼熱の古城＝「焦門／灰燼回廊…」、夢幻回廊リドパルム＝「夢入りの門／映し身回廊…」、災禍の根ジャゴレア＝「脈動根門…妄執根核」、次元牢獄クロノアビス＝「時止門…時獄最深部」へ固有化する。

内部event ID・mapId・floor番号はセーブ・参照互換のため名称変更しない。
