# 34_CRYSTAL_TREE_FOUNDATION_PHASE7B_20260810

## この工程の目的

結晶樹編を先に書き進めず、`7-6` 以降で必要になる状態・報酬・加入処理の正本を先に固定する。

今回は**長い会話本文、MAP規模、魔王軍直接戦闘②の敵編成を確定しない**。
それらを「実装しやすいから」という理由で勝手に決めない。

## 正本として既に確定していること

- 結晶樹の秘跡は本編必須。
- ルーナとレオンの双方が向かう理由になる。
- レイラは通常の結晶樹の葉で治療できたが、レオンには効かなかった。
- ソフィアから、結晶樹で研究しているミネルバの存在を聞く。
- ミネルバは六属性の役割と循環を理論化している。
- この時点でミネルバが断言できるのは六属性の真実まで。深淵・混沌・黒幕の全貌を説明役として語らせない。
- 結晶樹では魔王軍直接戦闘②が発生する。単純な侵略軍ではない違和感を残す。
- ルーナ正式加入後の必要経験値倍率は2000%。
- 結晶樹クリア時、ルーナへ一度だけ+300,000 EXP、必要経験値倍率1800%。
- 回想で到達したルーナのレベル・装備は正式加入時へ持ち越す。

## 今回固定する内部state

`worldState.crystalTreeState`

- 0: 手掛かり前
- 1: 行先判明
- 2: 秘跡到達
- 3: ミネルバ接触
- 4: 根源治療／防衛戦段階
- 5: 攻略済み

既存flagを消さず、save migrationではflagからstateを復元できるようにする。

## 今回追加するストーリーアクション

### STORY_EXP

- `charId`
- `amount`
- `rewardKey` 必須
- `App.grantStoryExp()` を通す
- 同じrewardKeyの再実行は二重付与しない
- 大量EXPでも既存の複数Lv処理を使う

### SET_EXP_MULTIPLIER

- `charId`
- `pct` 必須
- `App.setCharacterExpRequirementMultiplierPct()` を通す

結晶樹だけの専用処理にせず、魔王城・六精霊・将来の固定成長イベントにも同じ正本を使う。

## まだ決めないこと

- 結晶樹MAPのフロア数。
- 入口が水上都市の直結路か、ワールド上の独立地点か。
- 通常エンカウントの有無と敵候補。
- ミネルバと最初に会う具体的な位置。
- 魔王軍直接戦闘②の指揮官、人数、固定敵ID。
- ルーナ正式加入の正確なタイミング（秘跡到達直後／治療前後／戦闘後のどこか）。
- レオンが戦闘参加可能になる正確なタイミング。
- 六属性説明の会話文。

上記は章のプレイテンポと会話を一度通してから決める。

## Player Information Boundary

- `crystalTreeState`、EXP倍率、rewardKey等はプレイヤー本文へ出さない。
- ミネルバに六属性理論を一気に講義させない。樹の環境・治療の現象・魔法の反応と会話を組み合わせる。
- 「闇に支配の力はない」は重要な認識変化だが、結論だけをシステム文で表示しない。
- 魔王軍の目的もここで完全回答しない。戦い方・言葉の選び方で違和感を残す。
- MAP構造が決まっていない段階で、説明台詞を道案内の代用にしない。

## 次の実装順

1. 本foundationをvalidatorで固定。
2. 結晶樹の入口方式と最小MAP構造を既存ワールド導線と照合。
3. MAPだけ先に歩ける状態へ。
4. ミネルバ初対面までの短い会話案をMDで提示。
5. 承認・調整後にJSへ反映。
6. ルーナ正式加入／治療／直接戦闘②を別工程で接続。
