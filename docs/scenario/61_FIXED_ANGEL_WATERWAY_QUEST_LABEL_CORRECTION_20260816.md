# 固定ダンジョン天使・水上都市固定依頼・階層表示 補正（2026-08-16）

## 試練の天使

固定ダンジョンでは、その階の `encounterRank` を基準Rankとする。

- 左右個体: 基準Rank +10～+14。
- 中央個体: 基準Rank +15～+19。
- 試練用の追加ステータス倍率を適用する。現行master値は `1.35`。
- 固定ボス階には試練の天使を配置しない。
- 深淵ランダムダンジョン側の階層換算とは分離して扱う。

## 水上都市の固定依頼

ギルド以外の人物は依頼一覧UIを開かない。

暴動後の水上都市にいる旧「依頼仲介人」は「水路番」へ変更し、水路番本人から固定クエスト `water_city_hunt_waterway / 澄んだ水路の残火` を1件だけ受注・報告する。

`water_city_hunt_sanctum` / `water_city_hunt_black_armor` は将来配置可能なデータとして残すが、水路番から一覧提示しない。

## 階層名

通常階は原則として `1層 / 2層...`、地下構造なら `地下1階 / 地下2階...` とする。

研究棟、祭壇、最奥、固有の機能部屋など、通常階と区別する意味がある特殊階のみ固有名を使用する。

海底火山は地下1～3階を階数表記へ戻し、地下4階「沈圧研究棟」、地下5階「深海調律炉」は特殊階として維持する。
