# PRISMA ABYSS — Phase 2 プレイアブルプロローグ実装状況 v1

**作成日:** 2026-08-09  
**基準:** Phase 1 Complete Foundation  
**状態:** Phase 2A / 2B / 2C 完了（MAP・会話は意図的に最小骨格）

## 1. 実装済み通常ルート

- NEW GAME開始地点を、5年前の名もなき山村・西の高台へ変更。
- 西の高台 → 南エリア → 北エリアの仮3区画を追加。
- 西の高台で花採取中の日常、東の大閃光・遅れて爆発音・地震を骨格実装。
- 南エリア入場直後にルーナ救援戦。
- 5年前ルーナは本編ルーナID401ではなく、既存専用ID403「ルーナ（幼少期）」を使用。
- 救援後、アルス＋幼少ルーナの二人パーティで自由探索。
- 南エリア通常エンカウント、北エリア高Rank＋レア遭遇倍率を実装。
- プロローグ通常戦闘の全滅はゲームオーバーにせず、古き光の加護でその場復帰。
- 自宅消失イベント → 南口脱出 → 第一の深淵ボスを実装。
- 第一ボス直前に一時LB99加護。オート戦闘は禁止。
- 第一ボス敗北時：崩落・ペンダント・生き別れ骨格 → 一時ルーナ離脱 → アルス通常成長初期化 → 5年後リース山小屋。
- 焼け焦げたペンダントID701009を通常ルートで付与。

## 2. 第一ボス勝利・隠しルート

- 第一ボス勝利時は通常ルートへ即収束させず、深淵姫イルミナシア戦へ分岐。
- イルミナシア敗北：ストーリー進行3として通常の生き別れへ収束。
- イルミナシア勝利：ストーリー進行4へ。
- 進行4でリュシオンID501 / ゼノンID402をLv100・LB99で加入。
- 仮MAP「五年前・終焉の祭壇」MAP000070へ移動。
- イベント専用アゼルガラグID802003を追加。現行302100の0.5倍戦闘として使用。
- `bossStatMultiplier` が1.0未満も実際に適用されるよう戦闘生成を修正。
- 5年前variantは現行最終ボスの第二形態へ自動遷移せず、単独の不完全顕現として分離。
- アゼルガラグ戦は勝敗どちらでも特殊EDへ進み、ゲーム終了にはしない。
- 特殊ED後、5年後リース山小屋へ接続。
- 進行4特典として、アルス / 幼少ルーナ / リュシオン / ゼノンのLB99を保持。
- 幼少ルーナをtemporary状態から正式保持へ昇格し、本編ルーナと別IDで共存可能な土台を維持。
