# Phase8B Dark Castle Officers / Empire Shops Status v1

**Date:** 2026-08-10  
**Status:** implemented

## Implemented

- 三大魔族（ゼルドラス／エルメナス／ベレト）を全員男性として正典化。
- 三戦の会話をユーザー指定の戦闘理由へ更改。
  - ゼルドラス: 聖女保護、人間不信、闇プリズム再利用拒否。
  - エルメナス: 過去の闇プリズム奪取を根拠に人間を警戒し、観察と思考を試す。
  - ベレト: 思想ではなく魔王への謁見資格を実力で試す。
- 魔王城1Fのクリア後限定3ショップを削除。
- ガルヴァニア帝国に雑貨／武器／防具の3店舗を移管。
- 魔王城クリア前は店舗NPCが取引拒否、クリア後にRank65ショップへ切替。
