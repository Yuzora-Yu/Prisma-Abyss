# 転職の書・職歴システム実装仕様（2026-08-15）

## 1. 目的

各職業に固定IDを持たせ、「○○の転職の書」を職業マスターと連動して管理する。転職後も過去の職業で習得したスキルを失わず、将来の職業特性は現在職だけを参照できる基盤にする。

## 3. 転職の書

- Item ID: `710001` ～ `710023`。
- `jobId` から表示職業名を解決するため、職業名をアイテム側の正本にしない。
- 表示名: `○○の転職の書`。
- 取得経路は未設定。ショップ、ランダム宝箱、深淵宝箱からは出さない。
- 仲間モンスターには使用不可。
- 現在職と同じ職への使用は不可。

## 4. 使用条件と転職処理

表示Lv100でのみ使用可能。実効Lvは既存正本どおり、

`effectiveLevel = displayedLevel + reincarnationCount * 100`

を維持するため、使用時の実効Lvは100 / 200 / 300 ... の倍数になる。

成功時は次の順で処理する。

1. 現職の到達Lvと習得済みスキルを維持。
2. 現在職を指定 `jobId` へ変更。
3. 転生回数を1増加。
4. 表示Lvを1、EXPを0へ戻す。
5. 転職履歴へ記録。
6. 新職はLv1時点で習得対象となるスキルだけを補完。
7. セーブ。

別職で既に習得したスキルは `character.skills` に残り、転職後も使用可能。

## 5. キャラクター保存項目

- `jobId`: 現在職の固定ID。
- `jobTransferJobId`: プレイヤーの転職の書による現在職。ロード時の旧ストーリー職補正より優先する。
- `jobHistory`: 職歴の時系列記録。
- `jobProgress`: `jobId` ごとに、その職で実際に到達した表示Lvの最大値。

`jobProgress` は、新職Lv1なのに転生回数だけを見てLv100技能まで復元してしまう事故を防ぐために使用する。

## 6. ストーリー職変更との優先関係

アランの「光魔剣士覚醒」など、ストーリーが明示的に職業を変更する処理は `SET_JOB` が優先し、その時点のプレイヤー転職上書きを解除する。その後、プレイヤーが転職の書を使用した場合は再びプレイヤー選択職を保持する。

## 7. 職業特性

2026-08-16、全23職の職業固有特性を一括実装した。正本は `docs/design/JOB_TRAIT_SYSTEM_20260816.md`。

共通原則は従来設計どおり、**現在職と一致する職業特性だけを有効化する**こと。過去の `jobHistory` に含まれるだけでは旧職特性は発動しない。転職によって習得済みスキルは失わないため、「スキルは職歴を跨いで保持／特性は現在職だけ」という二層構造になる。

## 8. 転生の実による職歴復帰（2026-08-16）

`転生の実`（Item 107）は表示Lv100で使用する。現在職のまま転生する従来用途に加え、`jobHistory` に一度でも記録された過去職へは、対応する転職の書を消費せず戻ることができる。

処理原則:

1. 使用者が仲間モンスターでないこと、表示Lv100であることを確認する。
2. 選択肢は「現在職＋職歴に含まれる過去職」の重複なし一覧。
3. 過去職を選んだ場合は `jobId` / `jobTransferJobId` をその職へ切り替える。
4. 転生回数+1、表示Lv1、EXP0。
5. 全職で既に習得済みの `character.skills` は保持する。
6. 選択職についてはLv1習得対象だけを不足分補完し、過去の転生回数を理由に高Lv技能を自動習得しない。
7. `jobHistory` に `reincarnation_fruit_return`（同職なら `reincarnation_fruit`）として記録する。
8. 職業固有特性は転生後の**現在職**だけが有効。

職歴に存在しない職へ転職する場合は、引き続き対応する「転職の書」が必要。

## 9. セーブ互換

旧セーブは初回migrationで現在の職名を固定 `jobId` へ変換し、職歴と職別到達Lvを補完する。旧仕様で転生済みのキャラは従来の実効Lvベース技能復元との互換を維持する。
