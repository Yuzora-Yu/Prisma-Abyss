# 非MAPゲーム性基盤 — 2026-08-15（補正版）

## 方針

Phase19のMAP拡張・レイアウトは開発者の手描き構想を優先し、AI側では座標・地形・探索物配置を変更しない。
MAP非依存のゲーム性監査は継続するが、既存の計算思想や全職へ波及する新システムは、開発者との確認なしに変更・先行実装しない。

## 1. 転生後の必要EXP — 正式前提

必要EXPの基礎計算は今後も次を不変の前提とする。

`effectiveLevel = 表示Lv + 転生回数 × 100`

転生後に表示Lv1へ戻っても、必要EXPは実効Lv101、201、301...として既存曲線を継続する。
全体バランス調整で係数や必要量を再検討することはあっても、この実効Lvの考え方そのものは変更しない。

### 周回ごとの節目

転生後も育成上の節目を再び作るため、基礎EXP曲線を変えずに次だけを表示Lv基準で毎周回再適用する。

- 表示Lv49→50: その実効Lvで算出した基礎必要EXPに `WALL_50` を適用する。
- 表示Lv99→100: その実効Lvで算出した基礎必要EXPに `WALL_100` を適用する。
- 表示Lv50到達時: 既存の全ステータス成長ボーナスが再発生する。
- 表示Lv100到達時: 既存の全ステータス成長ボーナスが再発生する。

ステータス成長ボーナスは元から表示Lv50 / 100を条件としていたため、転生後も再発生する既存挙動を維持する。

## 2. 職業固有特性 — 未実装へ戻す

2026-08-15に狩人・魔弓使い・光魔剣士だけへ先行追加した `JOB_IDENTITY_DATA` と戦闘補正は撤回する。
職業固有特性は一部職だけ先行実装せず、開発者が各職の仕様を提示・確認した後に全職を同時に実装する。

撤回対象:

- `JOB_IDENTITY_DATA`
- `main.js` の職特性能力補正
- `battle.js` の職特性ダメージ・回復・弱体補正
- 仲間詳細の職特性表示
- 関連UI文言・NEWS記載

維持対象:

- 職業名変更
- 狩人・魔弓使い・光魔剣士という職業データ
- 各職の現時点の暫定習得技表
- アランの光魔剣士覚醒／恒久職変更

## 3. 今後の職業設計手順

1. 開発者が各職の特性仕様を提示する。
2. AI側で全職を横並びにし、役割重複・上位互換・武器条件・常時効果・数値強度を比較する。
3. チャット上で最終確認する。
4. 確定後、全職同時にruntimeへ接続する。
5. AUTO・戦闘計算・UI・セーブ互換を同時検証する。

## 4. MAP非依存で継続できる作業

- 地域推奨Lvと通常敵・ボスの能力帯監査。
- 店売り・固定報酬・ドロップの装備更新間隔監査。
- スキル参照切れ・イベント参照切れ・セーブ互換監査。
- Phase18のNPC背景/state設計。ただしMAP配置変更は行わない。
- 既存計算式を変更する必要が出た場合は、実装前に比較案をチャットで確認する。
