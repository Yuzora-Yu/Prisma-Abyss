# 非MAPゲーム性基盤 — 2026-08-15

## 方針

Phase19のMAP拡張・レイアウトは開発者の手描き構想を優先し、AI側では座標・地形・探索物配置を変更しない。
その間もロードマップを止めず、MAPへ依存しないPhase21の育成・職業・戦闘ロジックを先行する。

## 1. 転生後の必要EXP

旧実装は転生回数を実効Lvへ加算し、Lv101以降を別の緩い指数曲線で処理していた。
この方式では転生後にLv49→50 / Lv99→100の壁が消え、1周の育成リズムが平坦化する。

新方式では表示Lv1〜100の基本曲線を毎周回共通で使い、周回全体へ転生倍率を掛ける。

- 転生0回: ×1.00
- 転生1回: ×1.40
- 転生5回: ×3.00
- 転生20回: ×4.20
- 20回以降: ×4.20で固定

N基準・個別補正なしの場合:

- Lv49→50: 150,000 EXP
- 転生1回 Lv49→50: 210,000 EXP
- Lv99→100: 750,000 EXP
- 転生1回 Lv99→100: 1,050,000 EXP

既存のレアリティ倍率、大器晩成、個別EXP倍率はこの後段に維持する。

## 2. 職業固有特性

習得skill表とは別に `JOB_IDENTITY_DATA` を設ける。
これにより「同じskillを持っていても職が違えば手触りが変わる」状態を作る。

### 狩人

弓装備時のみ有効。

- 攻撃 +5%
- 命中 +8
- 会心 +4
- 物理ダメージ +5%
- ブレスダメージ +12%
- 毒・猛毒・感電・能力弱体の成功補正 +10%

狙撃だけではなく、獲物を崩して仕留める職として扱う。

### 魔弓使い

弓装備時のみ有効。

- 魔力 +8%
- 命中 +6
- 物理ダメージ +3%
- 魔法ダメージ +8%
- 回復量 +12%

AUTOの回復技評価にも回復補正を含め、手動時だけ強い状態を避ける。

### 光魔剣士

武器種条件なし。アランのストーリー覚醒職として扱う。

- 攻撃 +5%
- 魔力 +5%
- 魔防 +5%
- 物理ダメージ +4%
- 魔法ダメージ +4%
- 光属性攻撃 +15
- 光属性ダメージ +10%

中盤以降の光属性skillが明確な主力になるよう、単なる魔法戦士の名称違いから一段分離する。

## 3. UI

仲間詳細 > 成長の記録に「職特性」を表示する。
武器条件職は現在の装備で発動中かどうかも表示する。

## 4. データ健全性確認

- 武器6系統（剣・斧・短剣・杖・槍・弓）はrank1、10、20...200の基準帯に欠落なし。
- 全346モンスターの行動skill ID参照に欠落なし。
- 新3職の職特性はAUTO評価と実戦計算の双方へ接続する。

## 5. 次の非MAP工程

1. 地域推奨Lvと通常敵・ボスの能力帯比較。
2. 店売り・固定報酬・ドロップの装備更新間隔比較。
3. 六精霊・終盤ボスの実戦想定ターン／被ダメージ帯監査。
4. 新3職の専用skillは既存skill改稿を避け、新規skill案から作る。
5. Phase18 NPC背景/state文章は並行できるが、本筋・ゲーム性より優先しない。
