# PRISMA ABYSS 職業固有特性システム

更新日: 2026-08-16  
状態: ユーザー提示 `職業特性案.xlsx` を基準に初回実装

## 1. 共通原則

- 職業特性は固定 `jobId` に紐づける。
- **現在就いている職業の特性だけ**が発動する。`jobHistory` に過去職が残っていても旧職特性は発動しない。
- 転職の書で職が変わった場合、習得済みスキルは維持するが、職業特性は新しい現在職へ即座に切り替わる。
- 実質レベルは既存正本どおり `表示Lv + 転生回数 × 100`。この計算式は変更しない。
- 戦闘内で蓄積する特性値は新しい戦闘開始時に初期化し、戦闘中セーブからの復帰時は保存済み戦闘状態を引き継ぐ。
- 同種の全体常駐オーラが複数いる場合は、加算せず最も効果の高い一人分を採用する。

## 3. 原案から実装時に解釈を固定した箇所

### 魔法使い
内部数値欄には `現在MP/最大MP/2` とある一方、プレイヤー向け文には「MPが少ないほど」とある。職業コンセプトとして後者を優先し、**不足MP比率/2（最大+50%）**で実装した。

### 斥候
「全ステータス低下」「全属性耐性低下」の低下量が未指定だったため、初回値を20%相当としている。状態異常自体は指定どおり4ターン。

### 星詠師
ランダム効果の種類のみ指定され、威力・回復量が未指定だったため、初回バランス値を上表のとおり設定した。ここは実プレイ後の調整候補。

### 竜騎士
単体補正は「HPが低いほど急激に増え、最小0%、最大999%」という指定から三次曲線を採用した。

- HP100%: +0%
- HP75%: 約+15.6%
- HP50%: 約+124.9%
- HP25%: 約+421.5%
- HP10%: 約+728.3%
- HP0%近傍: +999%

実際にはHP0では行動できないため、999%は理論上限。

## 4. AUTO

AUTO固有判断を追加するのは以下。

- 戦士: 精神集中を使うため、一定確率でぼうぎょ。
- 狩人: 必殺を作るため、一定確率でぼうぎょ。
- 聖女: HP/MPが減っている味方がいる場合はぼうぎょ優先度を上げる。

既存の戦術AUTOを置き換えず、職業特性が専用行動を必要とする場合だけ先に候補判定する。

## 5. 表示

仲間詳細の「成長の記録」冒頭に、現在職の職業特性名と概要を表示する。転職後は現在職に合わせて即時切替する。

## 6. 今後の調整対象

今回の実装は「一度ゲーム内で動かして比較できる状態」にする初回値。以下は実プレイQAで再調整できるよう定数・独立関数へ分離している。

- 星巡りの回復量・威力
- 斥候の全能力/全耐性低下量
- 竜騎士の低HP曲線の指数
- AUTOでぼうぎょを選ぶ確率
- 全体常駐オーラの強さ
- 多段攻撃と被弾スタックの上限到達速度

数値調整を行っても、固定 `jobId`、現在職のみ発動、実質Lv計算式、職歴/スキル継承仕様は変更しない。
