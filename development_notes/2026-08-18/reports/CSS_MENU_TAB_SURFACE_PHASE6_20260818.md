# CSS Menu Tab Surface Phase 6 — 2026-08-18

## 目的

Phase 5 適用後の実機確認で、仲間詳細の「特性」ON/OFFと、ヘッダー直下に置かれるページ内タブの面構成に不統一が残っていたため、仲間詳細の「基本 / 装備 / スキル / 特性」を基準に整理した。

今回の基準は次の通り。

- 明るい茶色はヘッダーの面として使う。
- ヘッダーより下のページ面は `#130905` の暗い茶色に固定する。
- ページ内タブはページ面の上に独立した薄いブロンズ枠を持つ。
- 未選択タブは暗色、選択中タブは金色。
- ON/OFF系の「有効」はスキル使用設定と同じ金色、「無効」はグレー。
- フィルター等の別用途コンポーネントまでは今回タブ化しない。

## 実装内容

### 1. 特性ONを金色へ統一

`modern-polish-menu.css` の `.ally-trait-toggle.is-on` を、スキル使用可の `.skill-usage-toggle.is-enabled` と同じ金色グラデーション・暗色文字へ変更した。

OFFは従来どおりグレーを維持し、ON/OFFの意味を「金 / グレー」で統一した。固定特性や装備由来特性のバッジ色は役割が異なるため変更していない。

### 2. ページ面とヘッダー面を分離

従来の `.sub-screen` は、ヘッダー直下からページ上部にも明るい茶色のグラデーションが残る構造だった。これを `--menu-page: #130905` に統一し、ヘッダーだけが明るい茶色を担当する構造へ変更した。

`#party-screen-window` も同じページ面へ変更し、「仲間 / さくせん / そうび」周辺の余白がヘッダー色に見えないようにした。

メインメニュー本体 `#menu-overlay .menu-window` の背景は従来のまま維持している。

### 3. ページ内タブのレールを統一

共通 `.menu-tab-rail` を以下へ統一した。

- 背景: `--menu-page`
- 枠: 薄いブロンズ 1px
- 角丸: 7px
- 不要な内側ハイライトを削除

これにより「アーカイブ / 成長の記録 / 限界突破」「冒険の記録」「お知らせ」等の共通タブが、仲間詳細タブと同じ面構成になる。

### 4. 仲間編成・道具・セーブ設定タブも同じ思想へ寄せた

- `#party-screen-tabs`: ページ面 + 薄いブロンズ枠へ統一。重複していた同一セレクタの古い定義も1箇所へ集約した。
- `#item-tabs`: 上下線だけの旧形式をやめ、共通タブ同様の囲い枠・角丸へ変更。
- `.config-tab-bar`: 古い `#171717 / #444` のグレー配色を撤去し、暗い茶色 + ブロンズ枠 + 金色選択へ変更。
