# 光の宮殿 回想演出・再開安定化 Phase 11

日付: 2026-08-19
基準: Phase 10 + `LIGHT_PALACE` 3F罠範囲 X16〜18/Y20 hotfix

## 目的

光の宮殿回想の人物配置・退却演出・イベント戦闘を自然にし、イベント中UIを整理する。同時に、回想中の更新／手動セーブ読込でScene Contextが消えて進行不能になる問題と、回想用レイラLv50が現在時間の実績へ混入する問題を解消する。

## 実装内容

### 1. 3F 六芒星〜ヴェルド初戦

- 六芒星の発火範囲は X16〜18 / Y20 の3マスを維持。
- ジャスパーは発火時のレイラから真北2マスへ闇転移。
- ルーナ封印後、ルーナ `401` を回想パーティだけでなく回想中の仲間一覧から離脱。
- ジャスパー退場後、レイラを北へ1マス進め、ヴェルドをレイラの真北1マスへ闇転移。
- ヴェルド初戦の `endAfterTurns:5` を廃止。
- ヴェルドはイベント戦闘中 `hpFloor:1`。5ターン完了後に既存スキル `紫電の葬閃` (skill 140) を演出名として使用し、イベント専用の必中固定9999全体ダメージで強制敗北へ移行する。

### 2. レオン／クロード救援後の配置

救援後の最終配置を1マス左へ統一した。

- レオン: X16 / Y19 / 北向き
- レイラ: X17 / Y20 / 北向き
- クロード: X18 / Y19 / 北向き

北へ戻ろうとした場合のクロード制止イベントは X16〜18 / Y19 の3マスすべてで反応し、南へ1マス戻す。イベントは繰り返し可能。

### 3. 宮殿入口〜回想終了

- 入口戦のヴェルドもターン自動終了を廃止し、初戦と同じ5ターン後の必中固定9999全体技へ統一。
- 入口戦敗北後もヴェルドのマップ表示を残し、会話中に対峙状態を維持。
- 結界が一瞬消える台詞の直後に、フィールド全体へ大きな上下揺れを追加。
- クロード退場は一気に飛ばさず、レオンがクロードの北側へ回り込んだ後、クロード→レオンの順に南へ1マスずつ移動する押し出し演出へ変更。最後の画面外移動だけ長めにしている。
- 既存台詞・既存地の文面は変更していない。

### 4. イベント中の左上案内非表示

StoryManagerのイベント実行中は `#field-info-box` を非表示にする。

対象:
- 場所名
- G / GEM
- 現在の目的

右上のLOG／ミニマップ領域は対象外。イベント完了・エラー中断で元のdisplayへ復元し、再読込からイベントを再開する場合は再び非表示にする。

### 5. 回想中セーブ／再読込のScene Context永続化

従来のScene Contextはメモリ上の `App.sceneContextStack` にしか存在せず、手動セーブには回想中の一時 `App.data` だけが入るため、ロード後に `SCENE_PARTY` が `回想パーティを変更できませんでした。` で停止していた。

Phase 11では次を保存payloadへ格納する。

- 回想中の現在状態
- 回想開始前の現在時間側snapshot
- Scene Context stack
- checkpoint
- carryover / isolated inventory / exit trigger等のScene Context設定

`App.load()` でstackを復元するため、ブラウザ更新・オートセーブ・Phase 11以降に作成した手動セーブは回想冒頭へ戻らず現在位置から継続できる。

#### Phase 10以前の回想中手動セーブ互換

Phase 10以前の回想セーブには現在時間側snapshot自体が含まれていない。そこで以下の安全な互換復元を追加した。

1. 古い回想手動セーブをロードする時、上書き前のオートセーブが同じ進行段階の通常セーブなら、それを復元元に採用。
2. オートセーブが利用できない場合、他の手動セーブから `lightPalaceFlashbackReady` 済み・同一storyStepの最新通常セーブを探索。
3. 復元元を見つけた場合、Scene Contextとcheckpointを再構成してからロード。
4. 既に古い回想セーブをオート領域へ読み込んだ後でも、`SCENE_PARTY` / `SCENE_CHECKPOINT` / `SCENE_END` の直前に他の手動セーブから再探索する。

古い回想セーブしか残っておらず、対応する通常セーブが1件もない場合は、失われた現在時間側の仲間・装備・所持品を推測して復元しない。誤った古い通常セーブを自動採用しないため、復元候補には `lightPalaceFlashbackReady === true` を必須としている。

### 6. 回想状態と実績の分離

- `isolateCharacters` のScene Context中は実績進行チェックを停止。
- 主人公参照が必要な場合は回想用レイラではなく、Scene Context snapshot側の現在時間主人公を参照。
- これにより回想レイラLv50で主人公Lv50実績が解除されない。

### 7. イベント戦闘用フィニッシャー

`battle.js` にイベント戦闘専用の汎用ルールを追加。

- `finisherAfterTurns`
- `finisherSkillId`
- `finisherDamage`
- `finisherActorMonsterId`

通常戦闘には設定されないため影響しない。発動は1戦闘1回のみで、命中・防御・耐性・戦闘不能回避等を通さずイベント上の固定全滅として処理する。
