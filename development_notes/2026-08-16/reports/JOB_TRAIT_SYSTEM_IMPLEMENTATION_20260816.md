## 2. 不変仕様

実質レベルは次式を維持する。

`実質Lv = 表示Lv + 転生回数 × 100`

職業特性のレベル依存値もすべてこの実質Lvを参照する。

## 3. 戦闘基盤への接続

以下の既存経路へ共通特性フックを追加した。

- MP消費計算
- 強化効果ターン
- 攻撃/魔力/回避/会心/属性耐性などの戦闘ステータス
- 最終与ダメージ/被ダメージ
- 会心判定・会心倍率
- 命中/回避後処理・反撃
- 物理/魔法の行動履歴
- 被弾回数・撃破時処理
- 敵単体ターゲット選定
- 敵行動直前処理
- 戦闘終了ラウンド処理
- 戦闘用アイテム効果
- 戦闘不能/蘇生処理
- AUTOの職業固有ぼうぎょ判断

戦闘内で蓄積する値は `App.data.battle.jobTraitRuntime` に保持し、新規戦闘で初期化する。戦闘中セーブでは同オブジェクトを保持し、対象へ付与する職業特性状態は既存 `battleStatus` と一緒に保存/復元する。

## 4. ユーザー最終案から解釈を補った箇所

### 魔法使い
内部数値欄の式と「MPが少ないほど与ダメージ上昇」という表示文が逆方向だったため、表示文・職コンセプトを優先し、MP不足率に応じて最大+50%とした。

### 斥候
全能力低下・全属性耐性低下の量が未指定だったため、初回値は20%相当。4ターンは指定どおり。

### 星詠師
効果種類のみ指定だったため、初回値を以下とした。

- 偶数: 全体HP10% / MP10% / 主要能力1種+20%・3ターン
- 奇数: ランダム属性全体攻撃 / 主要能力1種-20%・3ターン
- 属性攻撃基礎値: `魔力×0.75 + 実質Lv×3`

### 竜騎士
低HP単体攻撃は、指定された0～999%を満たす三次曲線を採用。

`上昇率% = 999 × (1 - 現在HP/最大HP)^3`

参考値: HP75%=約15.6%、50%=約124.9%、25%=約421.5%、10%=約728.3%。

今回の目的は全23職を同時にゲーム内で比較できる状態へすること。数値未指定だった斥候・星詠師・竜騎士と、AUTO防御率、常駐オーラ、多段/被弾スタック速度は実プレイ後のバランス調整候補とする。

職業特性の設計変更を行う場合も、固定 `jobId`、現在職のみ発動、実質Lv計算式、職歴/スキル継承仕様は変更しない。
