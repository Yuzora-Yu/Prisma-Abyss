# 編成順マップ隊列・歩行画像 引き渡し

## 実装内容

- マップ上の表示順は `data.party` の編成順を使用する。
- 人間の仲間を先頭から最大4人まで表示する。
- `isMonsterAlly === true` の仲間モンスターは、表示だけでなく4人の人数計算からも除外する。
- 2人目以降は、先頭キャラクターが直前に通過したマスと向きを1マス間隔で追従する。
- 編成順を変更した場合、次回描画からキャラクター順へ即時反映する。
- マップ／階層／座標ワープ／移動手段が切り替わった場合は、古い軌跡を破棄して現在地から隊列を作り直す。
- 世界地図の端をまたいだ場合は、画面上で最短になる側へ追従位置を補正する。
- 飛行中、船上、浸水床上は主人公または乗り物だけを表示する。
- Phaser描画を正とし、互換Canvas描画にも同じ隊列情報を反映する。
