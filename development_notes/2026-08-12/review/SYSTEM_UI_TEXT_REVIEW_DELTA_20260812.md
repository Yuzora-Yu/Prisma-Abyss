# SYSTEM / UI 文言レビュー差分 2026-08-12

## ユーザー承認済み・今回反映

- 開発内部の都合で利用できない場合:
  - `今は利用できないようだ。`
- 未解放機能:
  - `まだ解放されていません！`
  - `条件を満たすと利用できるようになります。`
- 限界突破の成長上限:
  - `現在の成長限界に達しているようだ。`
- 正式機能名:
  - `魔道通信`

## 既存文言の整理

ユーザー承認に基づき、既存クエスト目的文から以下のような制作側分類を削除／自然化した。

- `加入クエスト`
- `隠し超強ボス`
- `超強ボス`

目的地・人物・行動を示す文へ寄せ、開発側の分類名をそのままプレイヤーへ見せない。

## チュートリアル

現在の `tutorial.js` 内容はsample扱い。

- 未発火のsampleは一覧へ表示しない。
- runtimeから実際に `TutorialModal.open(id)` が呼ばれた時点で既読登録する。
- 一度表示したものだけ、その後「お知らせ」内のチュートリアルタブから再確認できる。
