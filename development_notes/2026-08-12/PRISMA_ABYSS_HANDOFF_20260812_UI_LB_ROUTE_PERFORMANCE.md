## 基準

今回の基準はユーザー提供の `20260812_RPG最新版.zip`。
`assets/` と `.git/` は容量都合で未同梱だが、runtime / tools / docs はこのZIPを正本として確認した。

## 今回の実装

### 1. チュートリアル

- `tutorial.js` の39件は引き続きサンプルとして保持。
- 現時点では発火処理が未実装のため、サンプル一覧をプレイヤーへ公開しない。

- サンプル内の旧呼称「魔法通信」は「魔道通信」へ統一。

### 2. 限界突破

主人公:

- 「ストーリー進行」由来は最大 +10。
- 「探索深度」由来を廃止。以後、深淵到達階層からLBを増加させない。
- 旧セーブに残る探索深度由来の既獲得値は一度だけ `legacy` へ寄せ、値を失わない。
- 「戦闘回数」は勝利20戦ごとに +1。

共通:

- 「グロウプリズム」を維持。グロウプリズム使用分は `prism` として記録。
- 「死闘の経験」を維持。
- 「クエスト」「ボス討伐」「ガチャ重複」などの個別内部分類は画面へ出さず、末尾の「その他」へ集約。
- 「中間試練 +49→+50」「最終試練 +98→+99」と場所を説明する上部カードを削除。
- 現在の試練上限または最大値に達した時は「現在の成長限界に達しているようだ。」だけを表示。
- グロウプリズム使用時も試練名を直接説明せず、同じ成長限界表現へ統一。

試練そのもの、最果ての祠、頂の神殿のゲーム内イベントは削除していない。

### 11. 長時間プレイ / 水上都市 / 雷の要塞の軽量化

Cache Storageの画像キャッシュは削除しない。
RAM上のPhaser側だけを整理した。

`phaser-field.js`:

- `GRAPHICS.images` 全件を毎同期でPhaser textureへ昇格する処理を廃止。
- 実際にそのMAP描画で必要になった画像だけ遅延登録。
- MAP / floor scopeが変わった時、前MAPだけで使っていたPhaser textureを解放。
- 元Image / Cache Storageは保持するため、再訪時はネットワーク再取得ではなく手元Imageから再登録できる。
- フィールド以外のSceneへ移動した時はPhaser field sceneとgame loopをsleepし、戻った時にwake。
- Phaser fallback時はResizeObserverをdisconnect。
- GameObject破棄前に対象Tweenも停止。

水上都市:

- 広い水面で1tileごとに2個作っていた波Rectangleを、Graphics 1枚へまとめて描画。
- 水面imageそのものは維持。

雷の要塞:

- 電撃床装飾の無限Tweenを全対象ではなく決定的な約1/4へ制限。
- 静止装飾は残るため、電撃テーマは維持しつつ常時Tween数を削減。

### 12. 序章北側ハンター出現時の停止感

原因はハンター出現候補探索。
旧処理は全候補マスごとに `findShortestGridPath()` を繰り返していた。

修正:

- プレイヤー位置から一度だけBFSを行い、全到達可能マスの距離Mapを作成。
- 候補判定は距離Map参照へ変更。
- 従来と同じ到達可能性・最低距離条件を維持。

そのため、ユーザーが許可していた「恐ろしい魔物が次々に現れる…！」等の会話で停止を隠す処理は追加していない。

### 13. 時系列表現の残り

「アルスは五年間探し続けた幼馴染へ…」を
「アルスは探し続けた幼馴染へ…」へ整理した。
