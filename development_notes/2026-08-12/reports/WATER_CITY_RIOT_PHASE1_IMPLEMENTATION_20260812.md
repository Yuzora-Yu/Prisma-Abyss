# 水上都市暗黒騎士暴動 Phase1 実装報告 — 2026-08-12

## 1. 今回の実装境界

今回runtimeへ入れたのは、海底神殿クリア直後から始まる**水上都市暗黒騎士暴動5戦～クロード／レオン本格初登場～暴動後の聖女の噂**まで。

禁忌の森／ハイネ・アリサ救出以降は、ユーザー承認済みの正本へ更新したが、旧加入会話を途中だけ置換して進行を壊さないためruntimeは次実装単位へ分離した。

本編順は以下で確定。

`海底神殿 → 水上都市暴動 → 禁忌の森／ハイネ・アリサ → レクスノート地下 → 船・アラン`

## 2. Runtime

### 海底神殿クリア

`water_temple_clear` では旧 `waterCityCleared` を即時付与しない。

- `waterCityRiotReported`
- `waterCityRiotStarted`
- `waterCityRiotWave = 0`
- `waterCityState = 1`

を設定し、水上都市へ緊急帰還させる。

導入はソフィアからケイトへの水を介した緊急連絡。黒鎧の兵が住民へ剣を向けていることだけを簡潔に知らせる。

### 水上都市5戦

既存MAP上を移動しながら住民を救う5連続イベント戦とした。

1. 南門付近
2. 西の船渠
3. 中央水路
4. 北側の橋
5. 中央広場

既存イベント敵を再利用。

- `301021 ダークソルジャー` Rank32 / EXP760
- `301022 ダークナイト` Rank36 / EXP1300

新規敵ID・新規画像は追加していない。各戦は通常戦闘報酬を受け取り、勝利ごとに `waterCityRiotWave` を0→1→2→3→4→5と進める。

暴動中はソフィア、老人、船大工、元兵士、渡し守にも専用stateを設け、主人公が来るまで何もしていなかった街に見えないよう、避難・防衛・水路誘導を行わせる。

### 最終戦後

クロード／レオン率いる聖騎士団が到着し、二人の本格初登場とする。

クロードは負傷者救護と降伏兵保護を先に命じ、暗黒騎士が別系統部隊であっても「王国の鎧を着た者が民へ剣を向けた」責任を切り離さない。

レオンは民を守ったアルスたちの行動を事実として認める一方、王国の制止・国策を無視してプリズムへ踏み込む独断は正当化できないとする。民衆から「救世主」と呼ばれるアルスへの苛立ちには、組織に縛られず目の前の民を救える彼らへの嫉妬も含ませた。

クロードはレオンの気持ち自体は理解しつつ、民を救った事実まで曲げてアルスへ当たることを戒める。

最終処理で以下を設定する。

- `waterCityRiotWave = 5`
- `waterCityRiotSuppressed`
- `waterCityCleared`
- `waterCityState = 2`
- story subStep 5

### 聖女の噂

暴動後にのみ出る薄い噂として追加。

- 水上都市: 聖騎士団の評判から「王都の聖女」「魔族の拠点を聖なる光で浄化したらしい」という噂へつなぐ。
- カザリア: 「王都には奇跡を起こす聖女様がいるらしい」という商人伝いの噂を出す。

この時点ではルーナの名・容姿・正体を出さない。`lunaSurvivalRevealed` 後は噂NPCの優先表示を終了し、既知の事実になった後まで古い伝聞を残さない。

## 4. 今回正本化した次実装単位

禁忌の森／ハイネ・アリサについて以下をCanon・Roadmap・人物事典・Dialogue Review Queueへ反映した。

- ハイネ／アリサは旅の途中でカザリアへ立ち寄る。
- アリサは森奥の神殿から届く風の音を感じ、風のプリズムへ礼拝に行く。
- 礼拝後、風に導かれるように禁忌の森深部へ進んで戻らず、ハイネが後を追う。
- カザリア住民が、以前集落を救ったアルスたちを頼って水上都市へ救援要請に来る。
- ソフィアは救援へ送り出し、その間に船の持ち主を調べる。
- アリサは**ヴェリアで風へ旋律を捧げてきた楽師の家系**。
- 救出後、アリサ自身がプリズムを守る旅への同行を望み、ハイネも本人の意思を尊重して助力を申し出る。
- ハイネは**Bランク冒険者**。アレル＝レクスノート侯から護衛・討伐・輸送護衛等の仕事を何度か請けた古い仕事上の知人。
- 禁忌の森深部ボス後の**「古びた魔笛」（仮称）**は有力候補のまま。正式名称、Item ID、由来、用途は次実装開始時に決める。

## 6. 点検

ユーザー指示により、**同梱validatorは実行していない**。

実施した点検:

- `story.js` / `map.js` / `main.js` / `database.js`: `node --check` 4/4 PASS。
- 水上都市5戦のMAP座標: 5地点すべて歩行可能タイル。入口→各戦地点の到達性を確認。
- 5戦用story script / event / map actor / worldState条件の対応を確認。
- `301021` / `301022` のmonster定義存在を確認。
- 5戦に `noExp` 指定がないことを確認。
- 海底神殿クリア時には `waterCityCleared` を立てず、暴動最終鎮圧時にのみ設定することを確認。
- 旧セーブ互換で「海底神殿直後のみ新暴動へ接続」「先へ進んだセーブは巻き戻さない」を確認。
- 聖女の噂文中に「ルーナ」を出していないことを確認。`lunaSurvivalRevealed` 後は噂NPCの優先表示が終了することも確認。
- 既存変更ファイル12件の改行形式が基準版から変わっていないことを確認。

`assets/` は提供ZIPに含まれていないため物理アセット全件チェックは対象外。今回の第一単位は新規画像パスを追加せず、既存の暗黒騎士／住民overlayを再利用している。
