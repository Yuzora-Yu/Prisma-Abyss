Status: implemented / canon corrected / validated

## 1. 今回の確定仕様

2026-08-15 のユーザー補正を現行仕様として採用した。

- レガシオン神官がアルス達の多重属性加護と六プリズムに触れる既存会話は保持。
- 神官の話を受け、ミネルバが閃き、ソフィアと仮説を組み立てて六精霊巡礼を提案する。
- ゼノン／リーシアが加入済みの場合のみ、会話へ追加発言を挿入する。
- 任意加入キャラ差分はレガシオン専用にせず、再利用可能な `IF_ALLY` story action として実装する。
- 六精霊すべてに仲間側の会話を追加し、初回戦闘前の確認ダイアログを維持する。
- ヴェグナシスは五楔。ヴェルドは闇。ジャスパーはジャゴレア戦後に見限られて消滅済みで、終焉の祭壇には再登場しない。
- 指定された既存職業名を更新し、`狩人`／`魔弓使い`／`光魔剣士` を暫定定義する。

## 2. runtime 実装

### レガシオン → 六精霊巡礼

既存 `ABYSS_LEGACION_PRIEST` の2行は変更せず、その直後に新規イベント `abyss_spirit_pilgrimage_proposal_phase17` を接続した。

会話順は以下。

1. レガシオン神官の既存会話
2. ミネルバが神官の言葉から着想
3. ソフィアと観測／仮説を整理
4. ゼノン加入済みなら追加発言
5. リーシア加入済みなら追加発言
6. ミネルバが六精霊巡礼を提案
7. `abyssSpiritPilgrimageStarted` を成立

六精霊マップ側の開始条件も `abyssSpiritPrismKnown` から `abyssSpiritPilgrimageStarted` へ移し、「神官に聞いただけで各試練へ入れる」状態を解消した。

### 汎用 `IF_ALLY`

`story_logic.js` に追加。

- `charId` / `charIds`
- `mode: recruited | available | party`
- `match: all | any`
- `state: true | false`
- `then` / `else`

に対応する。

managed event では選択した分岐をイベントジャーナルへ保存するため、会話途中のセーブ／ロードや加入状態変化で同一イベント内の発言順が揺れない。

今回のレガシオンに加え、風精霊のアリサ差分にも同じ仕組みを使用しており、今後の任意加入キャラ差分へそのまま流用できる。

### 六精霊会話

既存の大精霊本文は保持し、新規仲間会話を追加した。

- 火：ガイル
- 水：ミネルバ
- 風：アリサ
- 雷：ジョセフ
- 光：ルーナ
- 闇：シャニー

初回試練は `大精霊会話 → 該当仲間会話（加入済みなら） → 既存の戦闘確認 → 戦闘` の順。勝利後にも各仲間の短い反応を追加した。

## 3. セーブ互換

### 六精霊巡礼

旧セーブがすでに試練へ進行済みの場合のみ `abyssSpiritPilgrimageStarted` を補完する migration を追加した。

単に神官へ話しかけただけの旧セーブは自動補完しないため、新しいミネルバ／ソフィアの提案会話を見られる。

### 職業名

旧セーブの職業名を新名称へ正規化する migration を追加した。

- `天地雷鳴士` / `天地雷鳴師` → `星詠師`
- `パラディン` → `聖騎士`
- `盗賊` → `斥候`
- `バトルマスター` → `剣闘士`
- `ゴッドハンド` → `聖拳士`
- `スーパースター` → `エンターテイナー`

ユーザー指定は `job.js` だったが、現プロジェクトで職業定義を持つ実ファイルは `job_data.js` なので、そこへ反映した。

## 4. 新規職業（暫定）

### 狩人

物理寄り。弱体、弓系として利用できる既存特技、ブレスを多めに配置した。

### 魔弓使い

攻撃魔法・回復魔法を厚めにし、弓系として利用できる特技を混ぜた。

### 光魔剣士

`魔法剣士` に近い前半構成から始め、中盤以降に強い光属性物理／魔法へ寄せる暫定構成とした。

習得レベル・特技構成は後日調整前提。

アランの現在職 `魔法剣士` は今回変更していない。`光魔剣士` への転職時期・条件は別途確定後に接続する。

## 5. canon 補正

以下を現行仕様へ修正した。

- ヴェグナシスは五楔。
- 五楔はグラド（火）／シーリス（水）／エリシア（風）／レナード（雷）／ヴェルド（闇）。
- ジャスパーはジャゴレア戦後、深淵王に見限られ消滅。終焉の祭壇では復帰しない。
- アランは地上側で光楔だったが、終局ヴェグナシスの構成員ではない。
- レガシオン神官 → ミネルバ着想 → ソフィアとの議論 → 六精霊巡礼、を正本化。
