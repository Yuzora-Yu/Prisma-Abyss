# ゲーム性・ロジック監査 2026-08-15

## 結論

現行runtimeに「システムの骨格だけあって何も動かない」規模の未完成は多くない。
一方、ロードマップ後半へ進む前に直す価値が高い、仮実装・将来改修耐性・ゲーム性の薄い箇所は残っている。

今回、実害が出やすい2点を先に実装した。

1. 固定探索物の開封状態が `x,y` 座標依存だった問題を `lootId` 対応へ変更。
2. 本編・町イベントから固定+装備を渡す汎用 `EQUIP` action を追加。

さらに、ツボ・タルが宝箱開封実績へ加算される問題を分離した。

## 今回の参照整合監査

- 固定MAPの `mapActors / mapActions` から参照するstory event: 欠落 0。
- MAP上のquest参照: 欠落 0。
- `requiredQuests`: 欠落 0。
- 2026-08-15 NEWS_DATA: 同日レコード1件を維持。

過去監査で疑義だった以下は現行コードでは大幅に堅牢化されているため、今回あえて旧仕様へ戻していない。

- 最速行動優先度: priorityを大きい桁へ分離して速度順より優先できる。
- 継続ダメージ後の死亡／勝敗: action endとround endで死亡反映・終了判定が行われる。
- 勝利報酬／保存: result journalとtransaction recoveryを持つ。

ただし上記3点は最終QAで実プレイも行う。

## 優先度A — ロードマップ中に扱うべき残件

### 1. Phase18 全地域NPC／日記／再訪差分

進行中。リュミナ、イグニシアに続き、今回カザリア、リヴァリアへ拡張した。
NPC追加だけでなく、探索物、再訪報酬、日記・生活物をマップ拡張と一緒に増やす。

### 2. Phase19 MAP拡張

開発者が手描き構想を先行するため、2026-08-15時点ではAI側のMAP本体編集を一時停止。
全町・固定ダンジョンを広げる際に、隠し道、ショートカット、レア敵、段差、生活導線、ツボ・タル・宝箱を同時設計する。
`actorId / stateId / lootId` はそのための先行基盤として維持する。

### 3. 新規3職の専用ゲーム性 — 基礎差別化まで対応済み

2026-08-15に職固有の常時／武器条件特性を実装。

- 狩人: 弓装備時に命中・会心、物理・ブレス、毒／弱体成功率を強化。
- 魔弓使い: 弓装備時に魔力・命中、魔法・回復、弓系物理へ補正。
- 光魔剣士: 攻撃・魔力・魔防、物理・魔法、特に光属性を強化。

専用弓技など習得技そのものの再編は、ユーザー指示どおり後続バランス工程で調整する。

### 4. 転生後の必要経験値曲線 — 仮実装を解消

2026-08-15に旧 `Lv101〜` 連続曲線を廃止。表示Lv1〜100の曲線を各転生周回で再利用し、Lv49→50／Lv99→100の節目を毎周維持する。必要EXPは転生1〜5回を強め、6〜20回を緩やかに増やし、20回以降は倍率を固定する。最終的な数値感はPhase21の実プレイQAで再評価する。

## 優先度B — ゲーム性を上げる次候補

- 町ごとに「序盤の小物」「再訪時の+装備」「少し隠した回復・状態回復」の報酬リズムを作る。
- 固定ダンジョンの一本道区画へ、鍵／一方通行／ショートカット／小型パズルのいずれかを適量入れる。
- レア敵を単なる低確率出現ではなく、地形・時間・探索行動と結びつけられる場所を増やす。
- NPCの間違った知識を、攻略上の罠ではなく「土地の常識と実際の仕様のズレ」として使う場合は、プレイヤーが検証可能な手掛かりを別に置く。
- +3固定報酬は店売り更新を殺さないよう、地域ごとに武器／盾／足など部位を散らす。

## 直ちに変更しないもの

- 既存会話の全面改稿。ユーザー相談が必要。
- 五楔ヴェグナシス、闇ヴェルド、ジャスパー消滅後不参加。現正本のまま。
- MAPを現サイズ前提で座標調整し続けること。Phase19で大きく変えるため、今はID基盤を優先する。

## 2026-08-15 非MAP先行追補

開発者がPhase19のMAP図面を先行する方針になったため、MAP本体を変更せずPhase21の非座標依存項目を前倒しした。

- 転生後の必要EXPを旧「実効Lv101以上」の仮曲線から周回式へ変更。Lv49→50 / Lv99→100の壁を毎周維持する。
- 転生EXP倍率は1回目1.4倍、5回目3.0倍、20回目4.2倍。20回以降は固定し、実績帯以降の青天井化を避ける。
- 狩人 / 魔弓使い / 光魔剣士へ `JOB_IDENTITY_DATA` を追加し、技能表とは別に職固有の戦闘ロールを持たせた。
- 弓条件職について、EQUIP_MASTERの弓がrank 1 / 10 / 20 ... / 200まで欠落なく存在することを確認した。武器更新側が職特性の足を引っ張る欠落はない。
- 魔弓使いの回復補正は実ダメージ・回復処理だけでなくAUTO回復評価にも反映し、AUTOが職特性を過小評価しないようにした。
- 仲間詳細「成長の記録」に職特性の説明と発動状態を表示する。
- MAP定義・座標・探索物配置は今回変更していない。
