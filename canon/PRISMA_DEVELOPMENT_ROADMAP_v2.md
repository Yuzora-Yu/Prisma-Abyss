# PRISMA ABYSS — DEVELOPMENT ROADMAP v2

**文書種別:** 新版シナリオ実装・段階開発ロードマップ  
**作成日:** 2026-08-09  
**位置づけ:** 正本4資料をコードへ落とす際の作業順序。設定判断は `PRISMA_SCENARIO_CANON_MASTER_v7` 等を優先し、本書だけで新設定を作らない。  
**基本目標:** 一気に全編を書き換えず、常に「次の地点まで遊べる」状態を作りながら前進する。

---

# 0. 開発原則

## 0.1 開発順

**設定 → 共通基盤 → 最小実装 → 通し確認 → 次章 → 本編通し完成 → MAP拡張 → 台詞磨き込み → バランス／最終QA**

ストーリー本文・MAP美術・NPC差分を最初から同時に完成させない。

## 0.2 各Phaseの完了定義

各Phaseは、コードを書いたことではなく以下を満たして完了とする。

- 想定開始地点からPhase終端まで進行不能にならない。
- save/loadで主要stateが維持される。
- 次Phaseが現在の仮実装を壊さず追加できる。
- 主要人物の「知っている情報」が前後で矛盾しない。
- 本編必須アイテム／加入／MAP遷移が取りこぼしで詰まない。
- 重大な不可逆分岐は警告・復帰導線を仕様どおり持つ。

## 0.3 MAP完成度を段階化する

開発者が最終図面を作成するため、AI実装側は本編進行中にMAP完成度を上げすぎない。

|段階|名称|内容|
|---|---|---|
|M0|進行骨格|出入口、壁、必須イベント地点、最低限の戦闘領域|
|M1|ストーリー機能版|NPC、イベント、エンカウント、セーブ復帰を含め通し可能|
|M2|探索拡張|宝箱、寄り道、レア敵、ショートカット、地域差分|
|M3|最終図面版|開発者図面を反映し、景観・生活感・探索密度まで完成|

**原則:** Phase 17まではM1を基準。M2/M3は後半のMAP Expansionでまとめて行う。

## 0.4 会話完成度を段階化する

|段階|目的|
|---|---|
|D0|イベントが成立する仮台詞|
|D1|情報開示・動機・感情・人物関係が破綻しない実装稿|
|D2|キャラ口調・テンポ・スキットとの整合を強化|
|D3|開発者による最終台詞調整|

AI実装側の主責任はD1までを安定して作ること。最終的な語彙・間・ニュアンスは開発者調整を前提とする。

## 0.5 検証の頻度

- 日常的なコード変更：構文チェック＋対象機能の局所テスト。
- 大きなPhase完了：関連validation。
- Phase 1、Phase 2、中盤大章、地上編完了、終章統合：`node tools/validation/run-all.js`。
- 最終：run-all + NEW GAME実プレイ + 主要分岐save + モバイル実機確認。

# 8. Phase 6 — 禁忌の森・ハイネ／アリサ必須加入

- 旅の途中でカザリアに立ち寄っていたアリサは、森奥の神殿から届く風の音を感じ、風のプリズムへ祈りを捧げるため単身礼拝へ向かう。
- 礼拝後、風に導かれるようにさらに禁忌の森深部へ進み、戻らない。ハイネが後を追う。
- 以前カザリアを救ったアルスたちを頼り、集落の住民が水上都市まで救援要請に来る。
- ソフィアは救援へ送り出し、その間に船の持ち主を調べる。

## 実装

- 既存禁忌の森MAPを再利用しM1化。
- 既存シルフウルフ／シルフフェアリー等を新版設定へ調整。
- ハイネ登場。
- アリサ登場。
- 二人の関係が説明だけでなく行動から分かるイベント。
- 風精霊異常／ヴェリア旋律等の伏線。
- ハイネ／アリサ正式加入。
- アリサは**ヴェリアで風へ旋律を捧げてきた楽師の家系**。古い祈りの旋律を、記憶ではなく身体の感覚として残している。

## 深部ボス後の貴重品【2026-08-13確定】

禁忌の森深部ボス後に **「古びた魔笛」（Item 701012）** を取得する。売却・使用不可の貴重品とし、現段階では追加機能を持たせない。内部正本ではヴェリア祭祀文化へつながる楽器だが、プレイヤーには出自を説明せず、風に触れて音を返すことと、アリサの指が笛穴を覚えていることだけを提示する。後のエリシア／ヴェリア線で意味を増やせる状態を維持する。
